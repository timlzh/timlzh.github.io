桃月拾伍日记

慢慢地开始思考上大学到底是为了什么，其实我一直觉得——或者说我一直想做的——就是学些技术提升能力，基础学科什么的，其实我一直不是很在意的。可是接触了很多人(特别是学长们)之后，我才发现很多人真的很卷，不论这个学科是什么，不上90分就是低分。我当时就觉得，哇，好累啊。
没有理想的人不伤心
冬月廿陆日记

喜欢一个人给我带来了什么，我从高中的最后时光开始就在思考这个问题。或许是一种对未来生活的向往？至少我很少对自己未来的成就抱有什么向往，成就这种东西我向来是得过且过的。但是情感不一样，像我曾经写的“柴米油盐勾勒的一定是生活”，我很喜欢对未来的琐事抱着向往。
曾经的信
冬月廿四日记

我以前一直觉得, 忘记一个重要的人, 需要多么的苦痛与伤心. 可事实却告诉我, 重要的人, 也只是轻轻地消散了, 慢慢的不见了. 突然有一天, 记得变成了想起, 才发现, 那个人已经不见好久了. 原来时间可以承受忘却的苦痛, 而我们只是失去, 失去的消失在背后的时间里, 一回头都已看不见了.
